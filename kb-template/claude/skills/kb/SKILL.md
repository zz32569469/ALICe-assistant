# kb：工作知識庫

知識庫位置：`{{KB_PATH}}`（以下稱 `$KB`）。
`$KB/CLAUDE.md` 是完整規範，本 skill 只是入口與摘要。**Analyze、Write-back、Lint 前先讀 `$KB/CLAUDE.md`**（含 §9 維護規範）與下方指定的流程頁；Query 不必整份讀，依 §9.3 用 Grep 查。

依使用者輸入判斷模式：

| 輸入 | 模式 |
| --- | --- |
| `/kb <問題>` 或一般提問 | Query |
| `/kb analyze <專案路徑>`、「分析這個專案進知識庫」 | Analyze |
| `/kb save`、「把這個記到知識庫」 | Write-back |
| `/kb lint`、「知識庫健康檢查」 | Lint |

## Query（查詢）

1. 讀 `$KB/wiki/index.md`，找出相關領域與頁面。
2. 問題中的用詞不確定時，用 Grep 查 `$KB/wiki/術語表.md` 的對應列（不整份讀）。
3. 讀相關頁面：
   - 通用原理、模式 → `$KB/wiki/<領域>/`
   - 某專案的具體做法 → `$KB/專案/<project>/00-總覽.md` 的「操作指南」表，再讀對應指南
   - 超過 1 萬位元組的頁先 Grep 標題（`^#`）定位，只讀需要的段落
4. 回答：
   - 附上引用的頁面路徑。
   - 知識庫沒有的內容明說「知識庫內無資料」，並標示哪些是一般知識推論。
   - 指南頁有 `basis`（commit）欄位；若使用者目前的程式碼版本不同，提醒行號可能已變。
5. 答案有長期價值（比較、決策、新關聯）時，詢問是否存成 `$KB/wiki/分析/` 頁（寫入依下方 Write-back）。
6. 需要跨很多頁彙整、或擔心讀太多占上下文時，可傳訊息給「知識庫管理員」session（名稱 `Library`）（`ListAgents` 找名稱）。

**不要**因為查詢而修改知識庫。

## Analyze（分析專案）

依 `$KB/_meta/流程/分析專案.md` 執行。重點：
- 先與使用者確認範圍與重點，除非使用者說「批次 / 不用問」。
- 被分析的 repo 一律唯讀。
- 產出：`wiki/來源/` 快照頁、`wiki/<領域>/` 通用知識（優先擴充既有頁）、`專案/<project>/` 操作指南、術語表更新、index / overview / log 更新。

## Write-back（回寫）

所有知識庫寫入由「知識庫管理員」session（名稱 `Library`）（開在 vault）執行，完整流程見 `$KB/_meta/流程/回寫協作.md`：
- **在專案 session**：不直接寫入。候選（前因後果、證據位置、通用或專案特有）先記在該專案更改紀錄的「待回寫」段落；階段結束、累積 10 則或使用者說「回寫」時，用 `ListAgents` 找「知識庫管理員」並以 `SendMessage` 整批傳送，配合管理員的反問，寫入後核對。會影響另一個角色正在做的事時立即送。
- **在管理員 session**：依下列步驟寫入。

1. 整理要寫入的內容：一句話摘要、屬於哪個領域、是通用知識還是專案特有。
2. 查 `$KB/wiki/index.md` 與術語表，決定「更新哪一頁」或「新增哪一頁」，擴充既有頁優先。
3. **向使用者說明要寫到哪裡、寫什麼，取得同意後才寫入。**
4. 寫入時遵守：
   - 用詞只用術語表的標準名稱或指定中文稱呼（別名欄第一個詞）；新詞先加入術語表。
   - 頁面結構依 `$KB/_meta/templates/`，寫法依 `$KB/_meta/寫作風格指南.md`。
   - 更新 frontmatter 的 `updated`、`projects`、`sources`。
   - 同一段說明只寫在一處，其他地方用 `[[連結]]`；寫入前先 Grep 有沒有頁面寫過。
   - 某專案的量測數據、調整結果只寫在知識庫外的專案紀錄，知識庫最多一句例子（`CLAUDE.md` §9.1）。
   - 寫入後檢查頁面長度（`wc -c`，位元組），超過 §9.2 上限就在同一次工作內拆頁。
   - 程式位置寫 `檔案:行號`（函式或條件名稱），與頁面 `basis` 不同版本時註明分支（§9.4）。
5. 新頁要登記到 `$KB/wiki/index.md`。
6. 在 `$KB/wiki/log.md` 末尾追加：
   ```
   ## [YYYY-MM-DD] writeback | <標題>
   - 新增 / 更新：[[…]]
   - 備註：發起專案 <路徑>
   ```
   每筆最多 3 行，不重述頁面內容（§9.5）。

## Lint（健康檢查）

依 `$KB/_meta/流程/健康檢查.md` 產出報告，**先列清單讓使用者確認**，不自動大改。
