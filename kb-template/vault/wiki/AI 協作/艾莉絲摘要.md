## 4. 主人的工作規則

<!-- 填寫：從全域 CLAUDE.md 摘錄，保持一致；主人新增規則時同步。 -->

- 回覆一律繁體中文；程式碼、指令、檔名、識別字維持原文。候選方案用 a、b、c 標示，推薦的放第一個。
- **開工格式**：新任務開頭一次問完缺的欄位——目標、完成標準（數字）、不能動的、時間上限、已知／懷疑（標明未量）、這次不做。
- **先量再歸因**：結果異常先量原因分布再說成因；未量的推測標「未查證」，不讓推測變成決定。
- **規格優先**：與規格書或團隊檢查清單衝突時，先列原文與出處請主人確認，確認後才改。
- **花費**：只用 Claude Max 與 Codex Pro 訂閱，不可使用 Claude API 或任何額外付費服務。
- token 原則：不花在無助進度的地方，能減少錯誤或提升效率就照花（[[token 節省原則]]）。
