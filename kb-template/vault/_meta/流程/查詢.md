# 查詢

> 規範仍以 `CLAUDE.md` 為準，修改本頁與修改 Schema 相同，要在 `wiki/log.md` 記一筆 `schema`。`/kb` skill 的 Query 段落是本頁的摘要。

可從本 vault 或其他專案（透過全域指引與 `/kb` skill）發起。

1. 讀 `wiki/index.md` 找相關領域與頁面；用詞不確定時先查 `wiki/術語表.md`（Grep 對應列，不整份讀，`CLAUDE.md` §9.3）。
2. 通用原理看 `wiki/<領域>/`，專案做法看 `專案/<project>/`；需要確認細節時，回到原始碼或 `raw/` 查證（唯讀）。
3. 回答時附 `[[連結]]` 或檔案路徑；wiki 查不到的要明說「知識庫內無資料」，並區分哪些是一般知識推論。
4. 答案有長期價值時（比較、決策、新發現的關聯），主動詢問是否回存到 `wiki/分析/`（寫入走 [[_meta/流程/回寫協作]]）。
5. 其他專案需要跨很多頁彙整時，可傳訊息給 [[知識庫管理員]]。
6. 查詢不修改知識庫。
