# 對外連結

> 修改 `CLAUDE.md` 的流程時先讀本頁，檢查下列各處是否要同步。規範仍以 `CLAUDE.md` 為準，修改本頁與修改 Schema 相同，要在 `wiki/log.md` 記一筆 `schema`。

- 全域指引：`~/.claude/CLAUDE.md` 的「工作知識庫」段落，讓任何專案的 Claude Code 都知道這個 vault 的位置與查詢方式。
- 查詢 skill：`~/.claude/skills/kb/SKILL.md`，提供 `/kb` 指令（查詢、分析專案、回寫）。
- Codex 轉址檔（只指向上述 Claude 版本，不複製內容）：
  - `~/.codex/AGENTS.md` → 全域指引
  - `~/.codex/skills/kb/SKILL.md` → `kb` skill（Codex 以 `$kb` 呼叫；frontmatter 的 `description` 需與 Claude 版同步）
  - vault 根目錄 `AGENTS.md` → `CLAUDE.md`
- Codex 轉址檔通常只需在路徑或 skill 描述改變時更新。
