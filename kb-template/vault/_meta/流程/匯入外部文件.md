# 匯入外部文件

> 執行這個流程前先讀本頁。規範仍以 `CLAUDE.md` 為準，修改本頁與修改 Schema 相同，要在 `wiki/log.md` 記一筆 `schema`。

文件放進 `raw/inbox/` 後觸發：讀全文 → **取得並檢視文件中的圖片** → 建立 `wiki/來源/` 摘要頁 → 更新相關領域頁與術語表 → 更新 index 與 log（`ingest`）。

圖片規則：
- 文件引用的圖片下載到 `raw/assets/<來源>/<文件名>/`，檔名保留原始 id；`raw/` 不可變規則同樣適用。
- LLM 以 Read 逐張檢視，把只存在於圖片的資訊（版面、欄位位置、範例數值、畫面）整理進來源頁的 `## 圖片發現`（表格：截圖 id、內容、寫入哪一頁），再寫入對應領域頁並註明「截圖」。
- 取不到的圖片（需登入、已失效）在來源頁「範圍」註明數量與原因，列為待補。需要登入才能取得的附件，註明取得方式。
