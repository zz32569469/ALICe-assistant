ALICe

at your service

在你自己電腦上執行的個人助理。她用 Claude Code 的訂閱思考，不用 API 金鑰、不會額外付費；對話、記憶、專案與截圖都存在本機。這一頁是可攜版的介紹，換一台電腦照下面的步驟就能裝起來。原始碼：github.com/zz32569469/ALICe-assistant。

  • Windows 已驗證
  • Node.js 20.19 以上
  • Claude Code（claude.ai 訂閱登入）
  • Codex 選用
  • MIT 授權
開啟網頁版 Studio →

網頁版 Studio 只是介面，要連到你自己電腦上的 Core：在那台電腦上填 http://127.0.0.1:7788；手機或其他電腦透過 Tailscale 連（見 repo 的 docs/手機連線.md）。用 setup 新裝的已經允許這個網頁連線；之前裝的要在 alice.local.json 的 remoteOrigins 加上 https://zz32569469.github.io 再重啟 Core。

她能做什麼 FEATURES

對話

  • 左邊分「工作」「聊天」兩個分頁，紀錄分開；聊天不帶專案資料，比較省 token。
  • Ctrl+V 貼上或拖曳截圖，她會先看圖再回答。
  • 長期記憶：聽到你的偏好會先記成筆記，每天整理一次，過時的會刪掉。

專案管理

  • 每個專案一張卡，進度線（流程可自訂）、任務清單、完成條件與負責的同事 session。
  • 同事回報做完時，先跳「進度等你確認」卡片和桌面通知，你按確認才更新。
  • 卡片可以收合；右上「更新進度」請她依任務清單核對。

日常

  • 會議：一行登記或在對話裡說，開會前 30 分鐘、10 分鐘各提醒一次。
  • 占卜：塔羅牌，今日運勢每天一次、本週運勢每週一次。
  • 用量：每次回覆的 token 與訂閱額度。

搭配的工具

  • Codex 分頁：委派給 Codex 的任務、回報與工作區比對。
  • alice-guard：Claude Code 的 mod，守提交規則、自動帶入角色頁，同事傳給她的訊息直送 Core。
  • Chrome 選取翻譯插件：選字按「譯」，用訂閱額度翻譯。

新電腦安裝 SETUP

  1. 事前準備

    • Node.js 20.19 以上。
    • Claude Code，用 claude.ai 訂閱登入；不要設定任何 API 金鑰。
    • Codex（選用），用 ChatGPT 訂閱登入。沒有的話，寫程式改由 Claude 做。
    • Obsidian，用來開知識庫。

  2. 下載並安裝

    setup 會安裝並建置 Core 與 Web Studio、建立知識庫範本與本機設定，最後做健康檢查。已存在的檔案不會覆寫。

    git clone https://github.com/zz32569469/ALICe-assistant.git alice
cd alice
node scripts/setup.cjs --kb <知識庫要放的資料夾>

  3. 啟用 alice-guard

    在 ~/.claude/settings.json 的 env 加上這一行，路徑換成這台電腦上 mods/alice-guard 的絕對路徑。健康檢查會印出可以直接貼的寫法。

    "CLAUDE_CODE_PLUGIN_DIRS": "C:\\…\\alice\\mods\\alice-guard"

  4. 啟動

    先開 Core，再另開一個終端機開 Web Studio，第一次會自動登入。

    cd core
npm start
    cd core
npm run studio

更新與檢查 MAINTAIN

更新會只允許快轉的 git pull，依變動重裝與重新建置，最後做健康檢查並列出要重啟的東西。

node scripts/update.cjs

健康檢查列出 Node 版本、建置、本機設定、知識庫與角色頁路徑、登入方式與 alice-guard 的狀態，每一項都附修正方式。

node scripts/doctor.cjs

資料放在哪 LOCAL

每台電腦各自獨立。git 裡只有程式、規格與範本，下面這些都留在本機。

內容位置進 git
對話、專案卡、會議、占卜、用量data/alice.db不進
貼上的截圖data/uploads/不進
事實檔與 ALICe 記住的事memory/facts.md不進
記憶整理前的備份data/memory-backups/不進
本機設定（知識庫、專案路徑）alice.local.json不進
alice-guard 設定mods/alice-guard/guard.local.json不進
程式、範本、說明文件core/ studio/ scripts/ docs/進

專案卡內建一條通用流程（規劃 → 進行中 → 驗證 → 完成）；團隊自己的流程寫在本機的流程設定檔，格式見 repo 的 docs/spec-projects.md。目前只在 Windows 驗證過；程式有 macOS／Linux 的分支，但還沒實測。最後一次在全新 clone 上完整安裝並啟動是 2026-10-12。
