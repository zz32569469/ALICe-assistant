# 用手機或其他電腦開 Web Studio（§58）

Core 只聽這台電腦本機（127.0.0.1）。要從手機或其他電腦開 Studio，用 Tailscale 建一個只有自己裝置的私人網路，再用 `tailscale serve` 把 Core 轉成有憑證的 https 網址。Core 不用改成對外開放，也不用開防火牆。

## 一次性設定

1. **這台電腦裝 Tailscale 並登入**：到 tailscale.com 下載 Windows 版，安裝後用自己的帳號登入（個人用免費）。
2. **手機裝 Tailscale 並用同一個帳號登入**（iOS／Android 都有）。其他要用的電腦也一樣。
3. **在 Tailscale 管理頁開 HTTPS**：admin console → DNS → 開啟 MagicDNS 與 HTTPS Certificates。
4. **在這台電腦把 Core 轉成 https**（PowerShell）：

   ```powershell
   tailscale serve --bg 7788
   ```

   執行後會顯示網址，例如 `https://<電腦名>.<tailnet>.ts.net`。`--bg` 會一直保留，重開機也有效；要取消用 `tailscale serve reset`。
5. **把網址加進 `alice.local.json`**，再重啟 Core：

   ```json
   "remoteOrigins": ["https://<電腦名>.<tailnet>.ts.net"]
   ```

   只收 `https://主機`（可以帶埠，不能有路徑）。沒加的話，網頁打得開但 API 和即時連線會被 Core 擋下（來源不在允許清單）。

## 在手機上登入

1. 手機開著 Tailscale，用瀏覽器開上面的網址。
2. 第一次會看到「需要登入」：貼上 token（這台電腦的 `%APPDATA%\alice\token`）。token 存在那個瀏覽器，之後不用再貼。
   - 也可以開 `https://<網址>/#token=<token>`，網頁會自動存起來並把網址裡的 token 清掉。

## 安全

- 只有登入同一個 Tailscale 帳號的裝置連得到這個網址；外人、同一個 Wi-Fi 的其他人都連不到。
- 還是要 token 才能看資料和對話；token 外流時刪掉 `%APPDATA%\alice\token` 再重啟 Core，會產生新的。
- 不要用 `tailscale funnel`（那會開放到整個網際網路）。
